`GET /orders` returns a paginated list of all orders placed by your API key. Use filters to query specific time ranges, statuses, or product categories.

## Endpoint

```
GET https://api.smartech-dz.com/v1/orders
```

## Authentication

All requests to this endpoint require a valid Bearer token. Include your API key in the `Authorization` header.

## Query Parameters

<ParamField query="status" type="string">
  Filter results to orders matching a specific lifecycle status. Accepted values: `pending`, `processing`, `completed`, `failed`, `refunded`. Omit this parameter to return orders of all statuses.
</ParamField>

<ParamField query="category" type="string">
  Filter results to orders belonging to a specific product category. Accepted values: `GIFT_CARD`, `PUBG_UC`, `FREE_FIRE_DIAMOND`. Omit this parameter to return orders across all categories.
</ParamField>

<ParamField query="from" type="string">
  ISO 8601 start datetime for the query window (e.g. `2024-01-01T00:00:00Z`). Only orders created at or after this timestamp are returned. Must be used together with `to` when filtering by date range.
</ParamField>

<ParamField query="to" type="string">
  ISO 8601 end datetime for the query window (e.g. `2024-01-31T23:59:59Z`). Only orders created at or before this timestamp are returned. Must be used together with `from` when filtering by date range.
</ParamField>

<ParamField query="reference" type="string">
  Filter results to orders that match an exact internal reference value you provided at creation time. Useful for looking up orders by your own system identifiers.
</ParamField>

<ParamField query="page" type="integer">
  The page number to retrieve. Defaults to `1`. Use together with `limit` to paginate through large result sets.
</ParamField>

<ParamField query="limit" type="integer">
  The maximum number of orders to return per page. Defaults to `20`. Maximum allowed value is `100`.
</ParamField>

## Request Example

```bash cURL
curl --request GET \
  --url 'https://api.smartech-dz.com/v1/orders?status=completed&category=FREE_FIRE_DIAMOND&from=2024-01-01T00:00:00Z&to=2024-01-31T23:59:59Z&page=1&limit=20' \
  --header 'Authorization: Bearer sk_live_your_api_key'
```

<ResponseField name="success" type="boolean">
  `true` when the request was processed successfully.
</ResponseField>

<ResponseField name="data" type="array">
  An array of order summary objects matching your query parameters. Returns an empty array `[]` if no orders match the applied filters.

  <Expandable title="Order summary fields">
    <ResponseField name="data[].id" type="string">
      The unique Smartech order ID. Pass this to `GET /orders/{id}` to retrieve full order details including delivery confirmation.
    </ResponseField>

    <ResponseField name="data[].status" type="string">
      The current lifecycle status of the order. Possible values: `pending`, `processing`, `completed`, `failed`, `refunded`.
    </ResponseField>

    <ResponseField name="data[].product_id" type="string">
      The product ID associated with this order.
    </ResponseField>

    <ResponseField name="data[].denomination_id" type="string">
      The denomination ID associated with this order.
    </ResponseField>

    <ResponseField name="data[].category" type="string">
      The product category for this order. One of `GIFT_CARD`, `PUBG_UC`, or `FREE_FIRE_DIAMOND`.
    </ResponseField>

    <ResponseField name="data[].player_id" type="string">
      The in-game player UID targeted by this order. Present only for `PUBG_UC` and `FREE_FIRE_DIAMOND` orders.
    </ResponseField>

    <ResponseField name="data[].reference" type="string">
      Your internal reference string provided at order creation.
    </ResponseField>

    <ResponseField name="data[].created_at" type="string">
      ISO 8601 timestamp of when the order was created.
    </ResponseField>

    <ResponseField name="data[].updated_at" type="string">
      ISO 8601 timestamp of the most recent status change on this order.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pagination" type="object">
  Metadata describing the current page position within the full result set.

  <Expandable title="pagination fields">
    <ResponseField name="pagination.page" type="integer">
      The current page number returned.
    </ResponseField>

    <ResponseField name="pagination.limit" type="integer">
      The maximum number of results per page as specified (or defaulted) in your request.
    </ResponseField>

    <ResponseField name="pagination.total" type="integer">
      The total number of orders matching your query filters across all pages.
    </ResponseField>

    <ResponseField name="pagination.total_pages" type="integer">
      The total number of pages available given the current `limit`.
    </ResponseField>

    <ResponseField name="pagination.has_next_page" type="boolean">
      `true` if there is at least one more page of results after the current page.
    </ResponseField>

    <ResponseField name="pagination.has_prev_page" type="boolean">
      `true` if the current page is not the first page.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="requestId" type="string">
  A unique identifier for this API call, useful when contacting Smartech support.
</ResponseField>

<Note>
  Orders are sorted by `created_at` in **descending order** (newest first). You cannot currently change the sort direction or sort field. To retrieve older orders, increment the `page` parameter or narrow your results using the `from` and `to` date range filters.
</Note>
