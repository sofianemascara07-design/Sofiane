Use this endpoint to exchange your `client_id` and `client_secret` for a Bearer access token. Include the token in the `Authorization` header on every subsequent request to the Smartech Recharge API.

---

## Endpoint

```
POST https://api.smartech-dz.com/v1/auth/token
```

---

## Request

**Headers**

| Header         | Value                               |
| -------------- | ----------------------------------- |
| `Content-Type` | `application/x-www-form-urlencoded` |

**Body Parameters**

<ParamField body="grant_type" type="string" required>
  The OAuth 2.0 grant type. Must be set to `client_credentials`. Any other value returns a `400 INVALID_GRANT_TYPE` error.
</ParamField>

<ParamField body="client_id" type="string" required>
  Your API client ID, issued by Smartech when you registered your application.
</ParamField>

<ParamField body="client_secret" type="string" required>
  Your API client secret, issued alongside your `client_id`. Keep this value confidential and never expose it in client-side code.
</ParamField>

---

## Request Example

<CodeGroup>

```bash cURL
curl -X POST https://api.smartech-dz.com/v1/auth/token \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  -d 'grant_type=client_credentials&client_id=YOUR_CLIENT_ID&client_secret=YOUR_CLIENT_SECRET'
```

```python Python
import requests

url = "https://api.smartech-dz.com/v1/auth/token"
payload = {
    "grant_type": "client_credentials",
    "client_id": "YOUR_CLIENT_ID",
    "client_secret": "YOUR_CLIENT_SECRET",
}
headers = {"Content-Type": "application/x-www-form-urlencoded"}

response = requests.post(url, data=payload, headers=headers)
token_data = response.json()
access_token = token_data["access_token"]
print(access_token)
```

```javascript JavaScript
const params = new URLSearchParams({
  grant_type: "client_credentials",
  client_id: "YOUR_CLIENT_ID",
  client_secret: "YOUR_CLIENT_SECRET",
});

const response = await fetch("https://api.smartech-dz.com/v1/auth/token", {
  method: "POST",
  headers: {
    "Content-Type": "application/x-www-form-urlencoded",
  },
  body: params.toString(),
});

const { access_token } = await response.json();
console.log(access_token);
```

</CodeGroup>

## Response

On success, the endpoint returns HTTP **200 OK** with a JSON body containing your access token.

<ResponseField name="access_token" type="string">
  The Bearer token to include in the `Authorization` header of all subsequent API requests. This is a signed JWT (JSON Web Token).
</ResponseField>

<ResponseField name="token_type" type="string">
  The token type. Always `Bearer`.
</ResponseField>

<ResponseField name="expires_in" type="integer">
  The number of seconds until the token expires, measured from the time of issuance. Typically `3600` (1 hour). Request a new token before this period elapses to avoid interruptions.
</ResponseField>

**Example Response**

```json
{
  "access_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_in": 3600
}
```

<Note>
  Store the `expires_in` value and track the token's age in your application so you can refresh it proactively rather than waiting for a `401` response.
</Note>

---

## Error Responses

| HTTP Status | Error Code            | Description                                                            |
| ----------- | --------------------- | ---------------------------------------------------------------------- |
| `400`       | `INVALID_GRANT_TYPE`  | The `grant_type` field is missing or not set to `client_credentials`.  |
| `401`       | `INVALID_CREDENTIALS` | The `client_id` or `client_secret` is incorrect or has been revoked.   |
| `429`       | `RATE_LIMITED`        | Too many token requests have been made in a short period. Back off and retry after the interval indicated in the `Retry-After` response header. |

<Warning>
  If you receive a `401 INVALID_CREDENTIALS` error and your credentials are correct, your secret may have been revoked or rotated. Verify your credentials in the Smartech developer dashboard and generate a new secret if necessary.
</Warning>
