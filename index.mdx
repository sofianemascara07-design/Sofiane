## How It Works

<Steps>
  <Step title="Get Your API Key">
    Contact Smartech to receive your API credentials and base URL for your environment.
  </Step>
  <Step title="Authenticate">
    Exchange your credentials for a Bearer token using `POST /auth/token`. Include this token in the `Authorization` header on every subsequent request.
  </Step>
  <Step title="Browse the Product Catalog">
    Call `GET /products` to retrieve available top-up products, denominations, and required player identifiers.
  </Step>
  <Step title="Place an Order">
    Submit `POST /orders` with the product ID, player identifier, and denomination. The API returns an order ID and processes delivery in real time.
  </Step>
</Steps>

<Note>
  All API responses are JSON. The base URL for all endpoints is `https://api.smartech-dz.com/v1`. Contact support if you need a sandbox environment for testing.
</Note>
